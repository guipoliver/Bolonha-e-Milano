# Bolonha e Milano

Jogo de estratégia econômica medieval em Python, construído em 8 etapas
incrementais.

## Como executar

Requisitos: Python 3.10+

    python -m src.bolonhaemilano.main

## Estrutura

- `src/bolonhaemilano/` – código do jogo
- `casos-de-uso/` – diagramas de casos de uso
- `uml/` – diagramas de classes

## Etapas

- [x] 1. Estrutura inicial, Main e menu
- [x] 2. Classes Jogador e Cidade
- [x] 3. Economia: florins, terras e grãos
- [ ] 4. Agricultura e população
- [ ] 5. Impostos e governo
- [ ] 6. Construções e soldados
- [ ] 7. Rodadas, múltiplos jogadores e vitória
- [ ] 8. Integração, testes e entrega final
